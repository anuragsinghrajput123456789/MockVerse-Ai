# MockVerse(AI) — REST API Reference & Request Lifecycle Flow 📡

This document outlines the formal REST API contract for the **MockVerse(AI)** platform. It details all endpoints, authentication parameters, request schemas, status code scenarios, and complete JSON transaction payloads.

---

## 🔑 Authentication Protocol

All core API endpoints (excluding registration and login) require a signed JSON Web Token (JWT) transmitted via the standard HTTP Authorization header using the **Bearer** format.

```http
Authorization: Bearer <JWT_TOKEN_HERE>
```

Failure to transmit the token, or presenting an invalid/expired token, yields:
- **HTTP Status Code:** `401 Unauthorized`
- **JSON Payload:** `{"message": "Not authorized, token failed"}`

## 🔒 1. Authentication Endpoints

### A. Register New Account
Creates a new student or educator profile and returns a signed session token.

- **Route:** `POST /api/auth/signup`
- **Authentication Required:** None
- **Content-Type:** `application/json`

#### Request Body
```json
{
  "email": "student@example.com",
  "password": "SecurePassword123",
  "name": "Arjun Sharma"
}
```

#### Response (HTTP 201 Created)
```json
{
  "_id": "603d2e1c9e830e2f54a8b7c1",
  "name": "Arjun Sharma",
  "email": "student@example.com",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpZCI6IjYwM2QyZTFjOWU4MzBlMmY1NGE4YjdjMSIsImlhdCI6MTYxNDU2NTYwMCwiZXhwIjoxNjE0OTk3NjAwfQ.example_signature"
}
```

#### Common Error Responses
- **HTTP 400 Bad Request (Duplicate User)**
  ```json
  { "message": "User already exists" }
  ```

## 📝 2. Question Paper Generation & Management

### A. Generate Custom Question Paper
Prompts Google Gemini AI with specific syllabus parameters, saves the result as a new document in MongoDB, and returns the entity.

- **Route:** `POST /api/papers`
- **Authentication Required:** Yes (Bearer Token)
- **Content-Type:** `application/json`

#### Request Body
```json
{
  "subject": "Physics",
  "class": "Class 12",
  "totalMarks": 70,
  "difficulty": "Hard",
  "board": "CBSE",

  "instructions": "Include at least one numerical application",

}
```

## 🤖 3. Intelligent AI Operations

### A. Generate Detailed Solution Guide
Instructs Gemini AI to compute step-by-step solutions for all questions in the generated test sheet, saving it to the database.

- **Route:** `POST /api/papers/:id/solutions`
- **Authentication Required:** Yes (Bearer Token)

#### Response (HTTP 200 OK)
```json
{
  "_id": "603d2f2d9e830e2f54a8b7c2",
  "solutions": "# Complete step-by-step Solution Guide\n\n### Section A: MCQs\n1. **Answer**: (a) q/ε₀.  \n   *Explanation*: According to Gauss's Law, the total electric flux is...",
  "updatedAt": "2026-06-02T13:05:00.000Z"
}
```

---

### B. Evaluate Student Responses
Grades submitted answer key strings, computes accurate score metrics, lists correction details, and stores the evaluation summary.

- **Route:** `POST /api/papers/:id/evaluate`
- **Authentication Required:** Yes (Bearer Token)
- **Content-Type:** `application/json`

#### Request Body
```json
{
  "answers": [
    { "questionIndex": 1, "studentAnswer": "The flux is q/epsilon_0." },
    { "questionIndex": 2, "studentAnswer": "Kirchhoff's current law is based on energy conservation." }
  ]
}
```

#### Response (HTTP 200 OK)
```json
{
  "_id": "603d2f2d9e830e2f54a8b7c2",
  "evaluationResult": "# Evaluation & Score Report\n\n## 📊 Overall Score: 62/70 (88.5%)\n\n### Question-by-Question Grading:\n1. **Score**: 5/5.  \n   *Feedback*: Perfectly accurate mathematical implementation.\n2. **Score**: 1/5.  \n   *Feedback*: Incorrect conceptual statement. Kirchhoff's Current Law is based on conservation of charge, not energy."
}
```

### C. Grounded Context-Aware Chatbot
Provides real-time interactive mentoring. The request attaches active paper and solution text context, grounding Gemini's chatbot window specifically in what the student is practicing.

- **Route:** `POST /api/chat`
- **Authentication Required:** Yes (Bearer Token)
- **Content-Type:** `application/json`

#### Request Body
```json
{
  "message": "Can you explain the derivation for Gauss's Theorem used in Question 3?",
  "paperContext": "# Physics Mock Exam\nQuestion 3: Derive Gauss's Law from Coulomb's Law...",
  "solutionContext": "## Solution Guide\nConsider a spherical Gaussian surface..."
}
```

#### Response (HTTP 200 OK)
```json
{
  "reply": "Of course! Let's break down the derivation step-by-step. Under Coulomb's Law, the electric field E is q/(4*pi*epsilon_0*r^2). When integrating E over the spherical Gaussian surface A = 4*pi*r^2, the r^2 terms cancel out beautifully..."
}
```
